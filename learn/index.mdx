# Learn by watching it work

Each topic answers one question, such as "what happens when…", with an animated flow you can play, pause and step through. Topics that compare tools get a comparison instead. Topics that are a list of ideas link out.

<TopicIndex roadmap={backendRoadmap} />

Topic names and their order follow the [Backend roadmap on roadmap.sh](https://roadmap.sh/backend). The diagrams and explanations here are my own. Go to roadmap.sh for the full map and its curated resources.
