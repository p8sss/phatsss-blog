# Learn by watching it work

Each topic answers one question, such as "what happens when…", with an animated flow you can play, pause and step through. Topics that compare tools get a comparison instead. Topics that are a list of ideas link out.

The roadmaps run in order: backend first, then frontend, then DevOps.

<LearnOverview roadmaps={LEARN_ROADMAPS} />

Roadmap names, section names and their order follow [roadmap.sh](https://roadmap.sh). The diagrams and explanations here are my own. Go to roadmap.sh for the full maps and their curated resources.
