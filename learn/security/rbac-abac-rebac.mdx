# RBAC vs ABAC vs ReBAC

**The question:** roles, attributes or relationships: which model fits?

**The short answer:** RBAC grants access by role and is simple to audit. ABAC evaluates rules over attributes and handles context. ReBAC follows relationships between users and objects, which suits sharing and hierarchies.

<CompareTable comparison={rbacAbacRebac} />

## They combine

Real systems mix models. A role can be one attribute in an ABAC rule. A ReBAC graph can grant a role on a folder that every document inside inherits. Start with roles and add the next model when roles stop fitting.

## Signs you have outgrown roles

- **Roles named after exceptions,** such as `editor-eu-except-billing`.
- **Per-object sharing** that roles cannot express.
- **Checks scattered through code** that combine roles with ownership and status.
